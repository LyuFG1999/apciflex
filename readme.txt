      do apciflex_article_example.do
  This generates apciflex_example.dta using mt64 and seed 12345 and reproduces
  section 4. The generated dataset contains 4,650 rows; estimation retains
  4,640 rows and 36 cells. No external data source is required.
  The simulated dataset is generated by the do-file.
